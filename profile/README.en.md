> Remaining v5 bugs will no longer be fixed. We are working to release v6 as soon as possible to fully replace the functionality of v5. Stay tuned.

We build an out-of-the-box desktop experience around [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), with composable plugins, curated packs, and UI skins.

The star badge totals all public repositories in the organization. The MIT badge links to the desktop project's license; each repository is governed by its own license.

## What we are building

| Project | Existing work and current status |
| --- | --- |
| [DSH-Desktop-EAC](https://github.com/DSH-EAC/DSH-Desktop-EAC) | The existing v5 desktop client bundles the runtime, desktop integration, plugin management, and interface customization. The v6 refactor is separating the host, plugins, and skin system. |
| [DSH Mojobox](https://github.com/DSH-EAC/dsh-mojobox) | An Alpha-stage foundation for a plugin catalog, function / appearance / workflow packs, version locks, and offline `.dshpack` builds. |
| [UI Skin Authoring Convention](https://github.com/DSH-EAC/DSH-Desktop-EAC-UI-Skin-Authoring-Convention) | Documents shared rules for controls, styles, slots, lifecycles, and compatibility, with ongoing alignment to the implementation. |
| [UI Skin Manager](https://github.com/DSH-EAC/dsh-ui-skin-manager) | Initial contract models, package validation, per-slot lifecycles, and fault isolation are in place. Production installation, runtime adapters, and EAC integration are still being developed. |
| [Default Skins](https://github.com/DSH-EAC/dsh-desktop-eac-default-skins) | The dedicated repository and contract boundaries for the official v6 default skin are defined. Source migration, per-region contributions, and reproducible releases are in progress. |

The organization profile and shared introduction live in [`.github`](https://github.com/DSH-EAC/.github).

## What's next

- **Advance the v6 refactor:** improve plugin integration, classification, and conflict handling, then verify coordination and stability across modules.
- **Connect the skin ecosystem:** integrate the host, skin manager, and default skin, and enable external layouts, styles, and flexible combinations.
- **Extend Mojobox:** continue work on host adapters, Profile / Preset packs, and account and publishing workflows.

Follow the [project board](https://github.com/orgs/DSH-EAC/projects/1/views/1) and each repository's Issues / Pull Requests.
