围绕 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)，构建开箱即用的桌面体验，以及可组合的插件、整合包和 UI 皮肤生态。

星数为组织全部公开仓库的总和；MIT 徽章指向桌面主项目许可证，各仓库以自身许可证为准。

## 我们正在做什么

| 项目 | 已有成果与当前进度 |
| --- | --- |
| [DSH-Desktop-EAC](https://github.com/DSH-EAC/DSH-Desktop-EAC) | 已有 v5 桌面客户端，提供运行环境打包、桌面集成、插件管理和界面定制；当前正在进行 v6 重构，推进本体、插件与皮肤系统分离。 |
| [DSH Mojobox](https://github.com/DSH-EAC/dsh-mojobox) | 已有插件目录、功能／外观／工作流整合包、版本锁定与离线 `.dshpack` 构建基座，目前处于 Alpha 阶段。 |
| [UI 皮肤创作公约](https://github.com/DSH-EAC/DSH-Desktop-EAC-UI-Skin-Authoring-Convention) | 已整理控件、样式、槽位、生命周期与兼容性约定，为皮肤创作和组合提供共同规则，持续与实现对齐。 |
| [UI 皮肤管理器](https://github.com/DSH-EAC/dsh-ui-skin-manager) | 已有契约模型、包校验、槽位生命周期与故障隔离等初步实现；生产安装、运行时适配和 EAC 集成仍在完善。 |
| [默认皮肤](https://github.com/DSH-EAC/dsh-desktop-eac-default-skins) | 已明确 v6 官方默认皮肤的独立仓库与契约边界；源码迁移、分区贡献和可复现发布正在推进。 |

组织主页与公共介绍由 [`.github`](https://github.com/DSH-EAC/.github) 仓库维护。

## 接下来

- **推进 v6 重构**：完善插件接入、分类与冲突处理，完成各模块协同和稳定性验证。
- **打通皮肤生态**：连接宿主、皮肤管理器与默认皮肤，推进外部布局／样式的接入和自由组合。
- **扩展 Mojobox**：继续完善宿主适配、Profile／Preset 包以及账号与发布流程。

具体进度见 [任务看板](https://github.com/orgs/DSH-EAC/projects/1/views/1) 与各仓库的 Issues / Pull Requests。
